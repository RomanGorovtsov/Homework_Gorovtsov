* get
  Возвращают только публичные элементы. Private, protected и package-private данные они полностью игнорируют. 
  Зато они видят публичные элементы, унаследованные от родительских классов.

* getDeclared
  Возвращают все элементы, которые объявлены прямо внутри конкретного класса, 
  вообще невзирая на их модификаторы доступа, но они не лезут в родительские классы.
